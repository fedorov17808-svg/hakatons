# 🧠 ОБЯЗАТЕЛЬНОЕ ПРАВИЛО: Автоматическая синхронизация с Obsidian Second Brain

## Триггер выполнения:
Агент ОБЯЗАН АВТОМАТИЧЕСКИ без напоминания со стороны пользователя обновлять и сохранять опыт в Obsidian vault:
- Путь к Vault: `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/мозги/`

## Когда выполнять синхронизацию:
1. **При завершении любого проекта, фичи или значимого этапа работы:**
   - Обновить/создать файл карточки проекта в `01 Projects/YYYY-MM-DD Название.md`
   - Записать актуальные эндпоинты, контракты, продакшн URL, метрики, количество пройденных тестов.
2. **При решении сложных технических проблем, багов, деплоев:**
   - Добавить/обновить сниппеты, паттерны и архитектурные решения в `03 Resources/<Категория>/`
3. **Перед объявлением задачи завершенной:**
   - Перед отправкой финального ответа пользователю ВСЕГДА проверять, зафиксированы ли последние изменения во втором мозге.

## Формат записи:
Всегда использовать `run_command` с heredoc (`cat > ... << 'EOF'`) для записи Markdown заметок по структуре PARA (Projects, Areas, Resources, Archive).
