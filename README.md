# 🚀 CreditPulse AI

**CreditPulse AI** is an autonomous AI risk-scoring agent built for Real-World Assets (RWA) and DeFi on Creditcoin during the **BUIDL CTC 2026 Fall Hackathon**.

## 🛠 Tech Stack
- **Frontend:** Next.js, Tailwind CSS, Viem / Wagmi
- **Backend & AI:** Python (FastAPI), LLM Risk Evaluation Engine
- **Smart Contracts:** Solidity (Creditcoin Testnet)

## 📁 Repository Structure
- `/backend` — FastAPI server & AI logic
- `/contracts` — Solidity contracts for Creditcoin
- `/frontend` — Next.js Web3 Interface
